# 離脱法の選び方

どのページから読もうか迷ったら、今の状況や気になることから選んでみてください。離脱や明晰夢を目指す方法には、目覚めた直後を使うもの、寝直す前に練習するものなどがあります。

## 状況から選ぶ

| 状況 | まず読む |
| --- | --- |
| 自然に目が覚めた後、夢へ戻ってみたい | [DEILD](techniques/deild.html)。夢から覚めた直後の短い再入眠を使う実践です。 |
| アラームで一度起きて、寝直す前に試したい | [WBTB](techniques/wbtb.html)と、組み合わせて研究された[MILD](techniques/mild.html)・[SSILD](techniques/ssild.html)。寝直す時間を確保できるときに。 |
| 起きている状態から明晰夢へ入る方法を、広く知りたい | [WILD](techniques/wild.html)。眠りに入る間も自覚を保つことを目指す、いくつかの進め方を紹介しています。 |
| 夢をあまり思い出せない | [夢日記](techniques/dream-journal.html)。覚えている場面や感情を、短いメモで残すところから読めます。 |
| 夜中にアラームで起きずに取り組みたい | [夢日記](techniques/dream-journal.html)。普段の目覚めで思い出した夢を記録できます。 |
| 金縛りの体験や、そこから試す方法を知りたい | [金縛りからの離脱](techniques/sleep-paralysis.html)。身体イメージを使う実践と、怖いときの対処・相談の目安を紹介しています。 |

## 入口をもう少し詳しく

### 寝直す前に、何をする？

WBTBは、一度起きて再び眠る機会を使います。その間に行う方法として、MILDは「次の夢で気づこう」という意図と、夢の中で気づく場面の想像を使います。SSILDは、視覚・聴覚・体の感覚へ順に注意を向けます。

各ページでは、具体的な手順と研究で使われた条件を読めます。SSILDには考案者の手順と研究版の違いも載っています。

### 思い出した夢を使いたい

夢日記に残した場面は、MILDで想像するときにも使えます。日記がまだなくても、思い出せる最近の夢があれば、それを使う手順を[MILDのページ](techniques/mild.html)で紹介しています。

### 小さな動きを使う方法が気になる

[FILD](techniques/fild.html)には、眠りに近い状態で指を小さく動かす実践があります。DEILDやWILDの後に進む段階ではなく、関心があれば読める別の方法です。

## ほかの方法も見る

[技法一覧](techniques/index.html)には、夢の記録、日中のリアリティチェック、明晰夢への入り方などをまとめています。気になる方法が変わったら、いつでもここから選び直せます。
