# MILD（記銘による誘発）

Mnemonic Induction of Lucid Dreams。「次に夢を見ているとき、夢だと気づく」という意図と、夢の中で気づく場面の想像を使う技法。系統的レビューでは、調べられた誘発技法の中で比較的強い裏付けがあると評価されている。全員への効果を保証するものではない。[^tan-2023]

## どういう技法か

あとで行うことを覚えておく「展望記憶」を利用し、次の夢で気づくことを狙う。LaBerge が開発し、1980年には本人の実践を対象とする初期報告が出版された。その後も誘発研究の対象になっている。[^laberge-1980]

## 研究で用いられた手順

以下は、中途覚醒後に行った Aspy 2020 の手順を中心とした要約。**この順序は研究手順の説明であり、全員に課す訓練コースではない。** この研究では就寝約5時間後に起きて実施した。最初の就寝時と比較して、ほぼ無効と示した研究ではない。[^aspy-2020]

1. **最近見た夢を思い出す。** 場面や出来事を思い浮かべる。
2. **次の夢で気づく意図を持つ。** 「次に夢を見ているとき、これは夢だと気づく」と心の中で繰り返す。単に言葉を唱えるだけでなく、思い出す意図を持つ。
3. **その夢の中で気づく場面を想像する。** 夢の不自然な点に気づき、「これは夢だ」と分かる自分を想像する。
4. **意図と想像を繰り返して、再び眠る。** 研究では、意図が定まったと感じるまで続けるよう指示された。最適回数や成功の閾値が確立したわけではない。[^aspy-2020]

直前の夢が出てこない場合、研究手順ではほかの最近の夢を使うことも認められている。[夢日記](dream-journal.html) は思い出した夢を残す方法の一つだが、記録を先に何週間続けなければならないという条件は設けない。[^aspy-2020]

## 効果について分かっていること

- 2017年の家庭研究では、RT・[WBTB](wbtb.html)・MILD を組み合わせた群47名のうち25名（53.2%）が介入週に1回以上の明晰夢を自己報告した。**研究全体169名の全員に対する成功率でも、MILD単独の成功率でもない。**[^aspy-2017]
- 2020年の家庭研究では、MILD と [SSILD](ssild.html) の成績に有意差は認められなかった。経験の有無による有意差もなかったが、厳密な同等性や全員への効果を保証しない。[^aspy-2020]
- 全群をまとめた探索的分析では、技法終了後10分以内の再入眠と成功の関連が報告された。**10分を守れば成功する、超えれば無効になるという結果ではない。**[^aspy-2020]

研究で試された MILD・SSILD の混合手順に上積みは認められなかった。ただし、あらゆる併用を検証した結果ではない。[^aspy-2020]

## 結果をどう見るか

目標は、夢を見ている最中に夢だと自覚すること。想像した場面が夢に出ただけでは、明晰夢や「効きかけ」とは判断しない。

意図を持つ段階と、夢の中で気づく想像の段階は、上記の手順にどちらも含まれる。一方、うまくいかなかった理由を「本気度が足りない」「想像が弱い」と決めつける根拠にはしない。

再入眠できない場合や睡眠に支障が出る場合、続ける必要はない。眠ることを優先し、回数や継続期間を一律に増やす指示は設けない。
