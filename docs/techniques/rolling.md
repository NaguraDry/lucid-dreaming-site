# ローリング

横へ寝返りを打つような感覚を使い、寝床から抜けるような体験を目指す方法です。海外の明晰夢コミュニティでも、寝床から転がり出るように感じ、そのまま明晰夢の場面に入ったという実践例が紹介されています。[^ld4all-rolling]

「最近幽体離脱にはまった まとめ」にも、イメージ式ローリング法として説明があります。ここでは、**身体のイメージの中で動く方法**を扱います。[^vip-rolling]

## 寝返りの感覚を思い描く

仰向けの姿勢から、横へゆっくり向きを変える感覚を思い浮かべます。まとめのイメージ式ローリング法では、手足を使わず、頭や肩から上体の向きが変わるようにイメージすると説明されています。回転の後に、浮き上がる感覚を思い描く手順も紹介されています。[^vip-rolling]

実際にベッドから転がったり、勢いよく起き上がったりする操作とは区別してください。体を動かす力を強めるより、イメージの中の感覚に注意を向けます。

## 金縛りの最中に試す場合

金縛りの状態から試す実践例や、浮く感覚などの別のイメージは、[金縛りからの離脱](sleep-paralysis.html)で紹介しています。まとめの参照先は「金縛り解除法」というページ名ですが、ここで扱うのは離脱へ入るための身体イメージです。金縛りを解いて目を覚ますための手順とは分けて読んでください。

転がる感覚を試さず、ふわりと浮く感覚を選ぶ方法もあります。まとめでは、人によって方法の向き不向きがあると説明されています。[^vip-rolling]

## 体験をどう捉えるか

まとめとLD4allの記事は、実践例を知る資料として参照しています。成功率や、どの方法が優れているかを比較した研究としては扱いません。[^vip-rolling][^ld4all-rolling]

覚醒から明晰夢へ入る流れは[WILD](wild.html)で紹介しています。体が抜けたように感じたかと、夢の中で「これは夢だ」と気づいていたかは、分けて振り返りましょう。
