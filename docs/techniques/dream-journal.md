# 夢日記

思い出した夢を記録し、後から振り返る方法。**日記そのものの誘発効果や、すべての技法での必須性が確立しているわけではない。**[^tan-2023]

## 研究で分かっていること

355名と169名が完了した誘発研究では、普段の夢想起の良さと明晰夢の成功との関連が報告された。ただし、この関連だけで「日記を書けば成功率が上がる」という因果効果は示せない。[^aspy-2020][^aspy-2017]

夢を思い出せなければ、夢を見なかったのか、見たが忘れたのかをその報告だけでは区別できない。記録は自分の報告を残す方法になるが、忘れた体験の価値がないという意味ではない。

[MILD](mild.html) は最近の夢を想像に用いるため、記録した夢を参照できる。直前の夢に限定せず、ほかの最近の夢を使うことも研究手順では認められている。[^aspy-2020]

## 記録する内容

夢の記録は明晰夢の実践書でも扱われている。[^laberge-book] ここでは、独自の誘発手順ではなく、記録する項目の例を示す。

- 思い出した場面、人物、出来事、感情。
- 夢だと気づいていたか。そう思ったきっかけ。
- 鮮明だったか、内容を操作できたか。自覚の有無とは分ける。
- 何も思い出せなかった場合は、そのこと。

紙や入力・音声メモなど、自分が扱いやすい記録方法を選べる。完全な文章にすることや、一定の本数を記録することを次の技法へ進む条件にはしない。

## 記録から分からないこと

- 1週間で夢の本数が何本増える、数週間で特定の段階に進むという標準値は、このページでは示さない。
- 「寝返りを打った瞬間に記憶の大半が消える」「画面を見れば記憶が飛ぶ」という一律の因果説明はしない。
- 記録に同じ場所や人物が繰り返し登場しても、それだけで特定技法の効果や人物の外部実在を示すわけではない。

夢日記単独の誘発効果が確立していないことは、「日記を書いても絶対に明晰夢は起きない」という意味ではない。[^tan-2023]

## 睡眠との両立

記録するために睡眠時間を削る必要はない。細部を埋めることや、毎回欠かさず記録することを義務にしない。睡眠を妨げる場合は、記録より眠ることを優先する。
