# 夢日記

夢日記は、思い出した夢を記録して、後から振り返るためのものです。覚えている場面や感情を、短いメモで残すところから始められます。

## 記録のしかた

夢を思い出したら、覚えていることを書き留めてみましょう。紙のノート、スマートフォンへの入力、音声メモなど、自分が使いやすい方法を選んでください。夢の記録は、明晰夢の実践書でも紹介されています。[^laberge-book]

長い文章にする必要はありません。たとえば「駅で昔の友人に会った。うれしかった」のように、場面や気持ちをひと言ずつ残すだけでも十分です。

## 記録する内容

何を書けばよいか迷ったら、次の項目を参考にしてください。

- **場面や出来事**：どこにいて、誰が登場し、何が起きたか。
- **感情**：うれしかった、驚いた、怖かったなど、どんな気持ちだったか。
- **鮮明さや自分の行動**：景色や感覚がどのくらいはっきりしていたか。夢の中で何をしたか。

何も思い出せなかった日は、「思い出せなかった」と残しておいても構いません。

## 記録を振り返る

後から読み返すときは、見た夢を思い出しながら印象に残った場面を追ってみましょう。同じ場所や人物が出てきた記録を見比べるのも、振り返り方の一つです。

[MILD（夢中自覚法）](mild.html)では、最近の夢を思い浮かべて、その中で夢だと気づく場面を想像します。日記に残した夢も、その素材にできます。直前の夢に限らず、ほかの最近の夢を使うことも研究手順では認められています。[^aspy-2020]

## 研究で分かっていること

355人と169人がそれぞれ最後まで参加した明晰夢の誘発研究では、普段から夢をよく思い出せる人ほど、明晰夢を体験しやすいという関連が報告されています。[^aspy-2020][^aspy-2017] ただし、夢日記をつけることだけで明晰夢が増えるかは、まだ十分に確かめられていません。[^tan-2023]
