# リアリティチェック（RT）

Reality Testing。「今は夢か」を考え、周囲や体の様子を確かめる方法。日中の練習が夢の中にも現れることを狙う用途と、夢の中で状態を確かめる用途がある。両者は評価する内容が異なる。[^aspy-2017]

## 研究で確かめられた範囲

2017年の家庭研究では169名が完了し、RT 単独の1週間の練習では有意な改善が確認されなかった。RT・[WBTB](wbtb.html)・[MILD](mild.html) の併用群では改善が見られたが、この設計から RT の追加寄与や必須性を独立には決められない。[^aspy-2017]

起きている間に練習できる一方、「MILD と必ずセットにする」「長く続ければ効く」「夢の中の確認なら必ず判別できる」といった結論は、この研究からは導けない。

## 確認方法の例と出典

### 研究で使われた確認

Aspy 2020 では、RT を追加する群に、**唇を閉じたまま口から息を吸おうとする確認**、または**片手の指を反対の手のひらへ押し当てる確認**が割り当てられた。これは研究に採用された手順の説明であり、夢と覚醒を完全に識別する診断精度を示したものではない。[^aspy-2020]

### 鼻をつまむ確認

鼻をつまんで呼吸できるか確かめる方法は、[FILD](fild.html) の考案者投稿などにも登場する。**上記の閉じた唇・口での確認とは別の操作**であり、これらの研究結果をそのまま鼻つまみの精度検証と見なさない。「最も確実」「間違えようがない」とは説明しない。[^fild-original]

手や文字、時計を見直す確認も実践書で紹介されるが、ここでは未確認の細部を研究手順に混ぜない。原資料を参照する場合も、その説明と検証された効果を分けて読む。[^laberge-book]

## 実践時の位置づけ

研究の RT は、動作だけでなく「今は夢か」と考えることを含む。何を確認し、どう判断したかという点と、動作の回数は別に扱う。[^aspy-2017]

この資料では、特定の確認を全員に一本化させたり、独自の毎日の回数や週間コースを課したりしない。うまく気づけなかった理由を「本気で疑っていない」「確認法を一つに絞っていない」と断定する根拠もない。

夢だという判断を、覚醒中の危険な行動の根拠にしない。高所から飛ぶなど、身体を危険にさらす確認は行わない。
