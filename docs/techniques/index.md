# 技法一覧

夢の記録、睡眠のタイミング、明晰夢への入り方を扱うページをまとめました。詳しい手順と根拠は各ページを参照してください。

どこから読むか迷ったら、[離脱法の選び方](../choosing-method.html)で、今の状況や関心に合うページを探せます。

全員が順番になぞる訓練コースや、次へ進むための回数・達成基準は設けない。関心のある項目から、手順の出典と確かめられている範囲を読んでほしい。以下の並びは、効果の順位や必須の実践順序ではない。

## 夢の記録と睡眠のタイミング

- [夢日記](dream-journal.html)：思い出した夢を記録し、振り返る。
- [WBTB](wbtb.html)：睡眠の途中で一度起き、再び眠る。他の技法と組み合わせた研究がある。[^aspy-2017][^aspy-2020]

## MILD と SSILD

- [MILD](mild.html)：夢の中で気づく意図やイメージを用いる。系統的レビューで、比較的強い裏付けがあると評価された技法。[^tan-2023]
- [SSILD](ssild.html)：視覚・聴覚・身体感覚へ順に注意を向ける。2020年の研究ではMILDとの成績に有意差はなかったが、厳密な同等性の証明ではない。[^aspy-2020]

同研究で試された混合手順は、比較した各手順を上回らなかった。あらゆる併用が無効、あるいは必ず一つだけ選ぶべきだと示す結果ではない。[^aspy-2020]

## 覚醒・入眠時からの移行

- [DEILD](deild.html)：夢から覚めた直後の再入眠を利用する実践。
- [Radugaの方法](raduga.html)：目覚め際に身体イメージや感覚を使う方法を切り替え、明晰夢を目指す。
- [WILD](wild.html)：覚醒から夢への移行で自覚を保つことを狙う方法や、その入り方を指す。
- [金縛りからの離脱](sleep-paralysis.html)：睡眠に伴う金縛りと、夢への移行に関する実践報告を分けて読む。[^foffani-2024]

これらは各ページで由来と検証の範囲を示す。短時間の移行を狙う説明があっても、その時間内の成功や負担のなさを保証するものではない。
