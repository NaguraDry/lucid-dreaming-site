# Radugaの方法（覚醒直後に試す方法）

目が覚めた直後に、起き上がるような感覚や浮かぶ像を使って、明晰夢へ入ることを目指す方法です。寝床から抜け出したように感じる体験にもつながります。

ここではRadugaの2021年論文にあるDCIMという手順を紹介します。使うのは、眠り始めではなく**目覚め際の像や感覚**です。[^raduga-2021]

## 具体的な進め方

### 1. 眠る前に、起きたら試すことを決める

「次に目が覚めたら試そう」と意図を持ち、以下の流れと、明晰夢に入ったらしたいことを思い浮かべてから眠ります。

### 2. 目覚めたら、体が動く感覚を試す

起き上がる、横へ転がる、浮くなどの感覚を、実際の筋肉を動かさずに試します。原著では一つにつき3〜5秒、2〜3種類を試す説明があります。目覚めてから大きく動いた場合は、この段階を飛ばして次へ進みます。

**ここでの動作は身体のイメージです。実際にベッドから転がったり、勢いをつけて起き上がったりしないでください。**

### 3. 像や感覚を使う方法へ切り替える

場面へ移れなければ、慣れた方法を2〜4種類選び、一つにつき3〜10秒ほどで切り替えます。原著の例には、次のようなものがあります。

- **像を眺める**：目を閉じたまま浮かぶ像を観察する。現れたら、その奥を見るようにして様子を捉える。
- **回転を感じる**：頭から足へ通る軸のまわりに、体が回る感覚を想像する。外から自分を見る映像より、回っている感覚に注意を向ける。

一巡しても変化がなければ、同じ方法を順に繰り返します。像や感覚がはっきりしてきたら、その方法を続けます。そこから自然に夢の場面へ入る場合と、再び起き上がるなどの感覚を試す場合があります。

### 4. 約1分で入れなければ、眠りに戻る

方法を切り替えても変化がなければ、約1分を目安に切り上げて再入眠します。原著では、次に目覚めたときにまた試す意図を持つよう説明しています。ここまでの秒数は原著の手順の目安です。[^raduga-2021]

> 眠る時間を十分に取り、何度も無理に起きようとせず、睡眠を優先してください。眠れなくなったり、怖さや苦痛が出たりしたら中断しましょう。

## 実践するときのコツ

眠る前に流れを思い浮かべておくと、目覚めたときに何をするか決めやすくなります。すでに像や動く感覚がある場合は、一から順番をなぞるより、その感覚を使うのが原著の説明です。[^raduga-2021]

金縛りになるのを待つ必要はありません。夢日記を書き続けてから始める、といった準備も、この手順にはありません。

## 研究で報告されたこと

12回の商業セミナーで、主に初日に数えた参加者は計449人でした。2夜の実践で、明晰夢は延べ484件報告されています。同じ人の複数体験や、夢の途中で夢だと気づいた例、短く不鮮明な体験も含む集計です。[^raduga-2021]

欠席や結果を聞けなかった人もおり、449人全員が最後まで実施・回答したデータではありません。484件は延べ件数で、成功した人数や各試行の成功率を示す数字ではありません。また、対照群との比較や睡眠中の生理的な確認は行われていません。著者は初心者が多数だったと説明していますが、初心者だけの人数・成績は集計されていません。[^raduga-2021]
