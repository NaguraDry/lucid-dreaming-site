# 離脱の4つの立場

「体外離脱」という語で扱われる主張や研究対象は一様ではない。本ページでは、引用資料を読み分けるために四つに整理する。**確立した学術分類ではなく、各立場の境界も必ずしも明確ではない。**

| | 主張・研究対象 | 検証の状態 | 研究例・注意点 |
| ---- | ---- | ---- | ---- |
| **1. オカルト的な説明** | アストラル体・界層などを用いる説明 | 検証可能性は個々の主張による | 本資料の実践上の前提にはしない |
| **2. 肉体を出る派** | 夢ではない何かが肉体を出る | この主張を裏づける再現可能な証拠は確立していない | 確立した再現性なし |
| **3. 明晰夢** | 夢の中で夢だと自覚する体験 | 無作為割付研究・系統的レビュー・眼球合図 | RT+WBTB+MILD群で1週間に1回以上報告した参加者53.2%（25/47、自己報告）[^aspy-2017] |
| **4. 神経科学の OBE** | 多感覚統合や身体自己意識から離脱感を検討 | HMD・触覚による身体錯覚、TMSによる課題干渉、電極刺激の事例 | 一部の身体錯覚は健常者でも誘発可[^ehrsson-2007][^lenggenhager-2007] |

この資料の技法ページは、睡眠に関連する離脱を明晰夢の枠組みで扱う。金縛りなどの関連現象を、すべて明晰夢と同一視するわけではない。4は身体自己意識を考えるための研究として紹介し、1と2は実践上の前提にしない。

## 1. オカルト的な説明

アストラル体や別世界などの説明を、ここで紹介する技法の前提には置かない。個々の体験報告と、その体験に与えられた霊的な解釈は分けて読む。本資料は、これらの世界観全体を検証・評価することを目的としない。

## 2. 肉体を出る派

身体を離れるという主張を扱う著作・団体の例として、次が挙げられる。

- Journeys Out of the Body[^monroe-1971]（Monroe 1971）— 「第二の身体」が肉体を離れる。行き先を Locale I / II / III に分類
- Waldo Vieira — 投射学（Projectiology）と意識学（Conscientiology）を提唱し、1988年にIIPCの設立に参加したと、同団体は説明している。これは主唱団体による自己紹介であり、主張の科学的な実証とは別である。[^vieira-iipc]
- Adventures Beyond the Body[^buhlman-1996]（Buhlman 1996）

分類1と説明が重なる場合もある。ここでは特に、身体の外から情報を取得できるという検証対象の主張に注目する。

**体験報告と、身体の外から情報を取得したという主張の検証は区別する。** 以下の研究だけで「不可能」と結論づけることもできない。

- Monroeを対象にした初期の実験室検査は、身体外からの情報取得を確立する結果にはならなかった — Tart 1998 著者による1967年検査の再検討[^tart-1967]
- 心停止2,060件を含むAWARE研究では、隠された視覚標的の識別は確認されなかった。ただし詳細面接は101人で、視覚的な記憶を報告した事例は標的のない場所で起きており、2,060人全員の標的検査ではない — Parnia 2014 AWARE研究[^parnia-2014]
- Blackmoreは自身の体験を含む検討を著書にまとめている。個人による書籍の評価を、全仮説の実験的反証と同一視しない — Blackmore 1983 Beyond the Body[^blackmore-1983]

ヘミシンクやモンロー研究所の個別の技術評価は、本ページでは扱わない。

## 3. 明晰夢

この資料の技法が目指す体験を扱う研究。[技法一覧](techniques/index.html)

以下の結果は対象者・実施条件・評価単位が異なり、技法の効果を直接順位付けする表ではない。

| | |
| ---- | ---- |
| RT + [MILD](techniques/mild.html) + [WBTB](techniques/wbtb.html) | **1週間に1回以上報告した参加者53.2%（25/47）**。研究全体は169名、自宅での無作為割付・自己報告比較研究。Aspy 2017 全豪明晰夢誘発研究[^aspy-2017] |
| [SSILD](techniques/ssild.html) + [WBTB](techniques/wbtb.html) | 夜あたり16.9%（SSILD群76名、自己報告）[^aspy-2020] |
| [TLR](techniques/tlr.html)（実験室） | **睡眠中にキューを受けた群の50%**。眼球合図と自己報告で確認。[^carr-2023] |

**一部の研究では、自己報告に加えて睡眠中の合図を使う。** REM睡眠中に事前に決めた合図を返すことが確認されている（LaBerge 1981 眼球運動による合図[^laberge-1981]、Konkoly 2021 夢との双方向通信[^konkoly-2021]）。自己報告以外の指標も使える。ただし、Aspyの自宅研究など、自己報告に基づく成績とは分けて読む。

## 4. 神経科学の OBE

視覚と触覚の操作や脳刺激によって、身体の位置・所有感の変化や離脱感が報告される研究がある。各研究で調べた現象は同一ではない。

- Ehrsson 2007 離脱感の実験的誘発[^ehrsson-2007] — HMD と触覚で健常者に離脱感
- Lenggenhager 2007 身体自己意識の操作[^lenggenhager-2007] — VR で自己位置が身体の外へずれる
- Blanke 2005 TPJへのTMS実験[^blanke-2005] — TMSで身体の心的変換課題を妨害。OBEそのものを直接誘発した実験ではない
- DeRidder 2007 電極刺激による離脱[^deridder-2007] — 1名の臨床事例で電極刺激に伴う離脱感を繰り返し報告

これらは**「体の外にいる感じ」や身体自己意識を研究するもので、「意識が体を出ること」を示したものではない**。一方、それだけで2のあらゆる主張が論理的に反証されたとまでは言えない。

## まとめ

**3（明晰夢）には睡眠中の客観的合図を伴う研究があり、4には身体錯覚を実験的に操作する研究がある。** 研究ごとの対象、成功率、再現性の限界は別々に評価する。

**ここに挙げた研究は、「意識が肉体を出る」ことを実証したものではない。**
