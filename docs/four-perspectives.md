# 離脱の4つの立場

「離脱」という言葉でも、どんな体験と考えるかは人によって違います。このページでは、その見方を4つに分けて紹介します。決まった学術分類ではなく、説明が重なるところもあります。

**このサイトでは、明晰夢の研究や実践をもとに方法を紹介します。** なじみのある「離脱」という呼び名を大切にしながら、目指す体験に近づく方法を考えていきます。

## 1. オカルト的な説明

アストラル体や別世界などを使って、離脱を説明する見方です。このサイトでは、こうした説明や、それに基づく方法は扱いません。

## 2. 肉体を出る派

夢の中の出来事ではなく、実際に体の外へ出ると考える見方です。たとえばモンローの著書では、「第二の身体」が肉体を離れる体験が語られています。[^monroe-1971] ただし、体から抜けたと感じることと、実際に体の外へ出たことを確かめるのは別です。

ヘミシンクやゲートウェイなど、モンロー研究所に由来する手法はここに含まれます。[^monroe-methods] こうした手法に親しんでいる方もいますが、このサイトでは扱いません。

## 3. 明晰夢

明晰夢は、夢の中で「これは夢だ」と自覚している夢です。明晰夢を見やすくする練習や方法が研究されています。[^aspy-2020]

**このサイトでは、明晰夢の研究や実践をもとに、離脱を目指すときにも参考になる方法を紹介します。** 離脱と明晰夢をすべて同じものと決めつけず、共通する方法に注目します。

## 4. 神経科学の OBE

OBEは「体外離脱体験」の略です。この分野では、「自分はどこにいるか」「どれが自分の体か」という感覚を調べます。映像や触覚、脳への刺激を使う研究がありますが、それぞれ調べている現象は異なります。

- **映像と触覚による離脱感**：頭に装着する映像機器と触覚を組み合わせ、健康な参加者に離脱感を生じさせた実験です。[^ehrsson-2007]
- **自分がいる位置の変化**：VRを使い、自分がいると感じる位置が体の外へずれることを調べた実験です。[^lenggenhager-2007]
- **体の向きや視点を頭の中で変える課題**：脳への磁気刺激で、この課題の成績に影響が出ました。離脱体験そのものを起こした実験ではありません。[^blanke-2005]
- **電極刺激に伴う離脱感**：1人の患者で、脳への電極刺激に伴う離脱感が繰り返し報告された事例です。[^deridder-2007]

これらは「体の外にいる感じ」を理解するための研究で、意識が実際に体を出たことを示すものではありません。
