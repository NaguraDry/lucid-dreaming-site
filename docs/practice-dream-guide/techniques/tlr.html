実践ガイド・階層確認用 · PR #101

TLR（感覚キュー）

Targeted Lucidity Reactivation。睡眠前の認知訓練と、睡眠中の音や光などの感覚キューを組み合わせる研究手法。実験室版だけでなく家庭版も研究されているが、条件と限界を分けて読む必要がある。12

何を狙う研究か

睡眠前の訓練で、気づきや注意の持ち方を感覚キューと結びつけ、睡眠中に同じキューを提示することで再活性化を狙う。提案される仕組みと、実際に確認された結果は別である。 すべての試行で意識的に音を聞き、必ず同じ心の状態が戻ると確立したわけではない。2

MILD や リアリティチェック との違いは、睡眠中に外部からキューを提示する点。夢だと気づく判断自体が不要になったり、技量に左右されなくなったりすることを示したものではない。12

研究手順の構成

以下は研究の共通する構成を説明するもので、機器設定まで再現した実践マニュアルではない。

  1. 睡眠前の認知訓練：キューに合わせて、気づき・注意に関わる練習を行う。
  2. 睡眠中のキュー提示：実験室版では REM 睡眠を判定して提示する。家庭版では脳波判定を用いないスマートフォンの方法も検討されている。
  3. 結果の評価：明晰夢の自己報告や、実験室では眼球合図などを用いる。12

キューの種類、提示時刻・音量、訓練内容、評価方法は各論文の条件に依存する。一定の音楽やホワイトノイズを小さく流し続ける独自の手順に置き換えて、同じ研究の裏付けがあるとは扱わない。

効果について分かっていること

  • 実験室の90分の仮眠機会では、睡眠中にキューを受けた群の50%に、眼球合図と自己報告を伴う明晰夢が確認された。キューを受けない群では17%だった。全参加者・全家庭実践に共通する成功率ではない。1
  • 2024年の家庭研究でも明晰夢の自己報告が増えた結果がある。ただし脱落、解析対象の選び方、夢想起、自己報告、睡眠分断などの制約がある。2
  • 実験室と家庭研究は、機器や参加者だけでなく評価方法も異なる。差の原因を REM 判定精度だけに求めたり、単純な成功率ランキングにしたりしない。2

実践資料として読む際の注意

家庭版が研究されていることと、特定の市販機器の有効性が確認されたことは別。研究手順のどこを再現しているのか、睡眠への影響をどう扱うのかを確認する必要がある。2

このページでは、研究から発想を借りた独自の混成手順や、音楽の連続再生案は提案しない。実際に研究で用いられた訓練や提示条件は、原論文に帰属させて説明する。
