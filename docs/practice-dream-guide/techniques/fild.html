実践ガイド・階層確認用 · PR #101

FILD（指を小さく動かす）

Finger Induced Lucid Dream。眠りに近い状態で指を小さく動かし、夢への移行を狙うコミュニティ由来の技法。2004年の Hargarts の投稿に手順がある。1

WILD に関連する実践として扱われる。FILD 単独の効果や仕組みを検証した査読比較試験は、今回確認した範囲では見つからなかった。検証が限られることを理由に、技法を選ぶ余地まで否定するものではない。

原投稿に基づく手順

以下は Hargarts の説明の要約であり、研究で効果が確立した手順ではない。1

1. 夜間・朝の覚醒後、再び眠りに近づく

原投稿は、目覚めた後に眠りに落ちそうな状態を利用する。特定の時間帯以外では無効と実証されたわけではない。

2. 指を小さく動かす

人差し指と中指を、交互にごく小さく動かす。原投稿は、ピアノの鍵盤を押すような動きを小さくしたものとして説明している。

3. 10〜30秒ほどを目安に確認する

この時間は原投稿の指示であり、夢へ入るまでの実測平均や成功の締切ではない。原投稿では秒数を厳密に数えず、その後に鼻をつまんで呼吸できるか確かめる リアリティチェック を提案している。

鼻つまみはコミュニティの確認法であり、誤判定のない検査として検証されたものではない。異常な結果があれば必ず夢だ、通常の結果なら必ず覚醒している、と断定しない。

4. 入れなかった場合

原投稿では数分休んで一度再試行し、それでも入れなければ眠るという説明がある。これはそのガイドの手順であり、この資料が独自に定めた反復義務ではない。眠りを妨げてまで続ける必要はない。

結果の捉え方

指を動かして眠れない場合、確認を忘れた場合、普通に眠った場合などがあり得る。ただし、それぞれの原因を「動かしすぎ」「眠りが浅い」「意図が弱い」と一意に決める根拠はない。

「30秒でできる」「損失がない」「何度でも続けられる」とは保証しない。原投稿の実践上の提案と、効果・安全性の検証は区別する。1
