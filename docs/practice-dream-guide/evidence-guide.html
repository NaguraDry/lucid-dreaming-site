このサイトの根拠の読み方

「どんな方法なのか」「試した人はどうだったのか」を知るために、このサイトでは研究論文と実践者の説明を紹介しています。知りたいところから読めるよう、手順は各技法のページにまとめています。このページは、出典や数字が気になったときの案内です。

研究と体験談は、それぞれ何を教えてくれるか

実践記事やコミュニティの投稿からは、具体的なやり方や、本人が使っているイメージ、試行錯誤の工夫を知ることができます。一方、うまくいった人の報告だけでは、試した人全体のうち何人に役立ったかは分かりません。

研究では、参加者や期間、行う手順、結果の確かめ方を決めて調べます。たとえばAspy 2020は、自宅で技法を試し、夢や睡眠について記録する研究です。1 「研究で分かっていること」の欄では、誰が何を試した結果なのかを添えて紹介します。

まだ十分に調べられていない方法には、これから確かめる余地があります。「未検証」は「効果がないと分かった」という意味ではありません。また、比較で差が見つからなかった場合も、同じ効果だと確認できたとは限りません。

同じ名前でも、手順が違うことがある

技法名が同じでも、紹介者や研究によって、起きる時刻、注意の向け方、繰り返し方が違うことがあります。たとえばWBTBには、就寝約5時間後に自宅で起きる研究と、約6時間後に実験室でREM睡眠から起こす研究があります。12

各ページでは、どの資料の手順を紹介しているかを示します。研究結果を読むときは、名前だけでなく、実際に試されたやり方も合わせて見てください。

「何％」は、何を数えた数字か

同じ「成功率」という言葉でも、分母や期間が違うと数字の意味が変わります。

  • 人の割合：一週間に一度以上、明晰夢を報告した人は何人いたか。
  • 夜の割合：記録した夜のうち、明晰夢を報告した夜はどれくらいあったか。
  • 体験の件数：何件の明晰夢が報告されたか。一人が複数件を報告することもあります。

たとえば、10人が7夜ずつ記録し、5人が一度ずつ明晰夢を報告したとします。経験した人は50％ですが、報告のあった夜は70夜中5夜、約7％です。これは数え方を説明するための架空の例です。

期間や人数に加えて、何をもって明晰夢としたかも大切です。本人の報告で数える研究と、睡眠中の眼球合図まで確認する研究では判定の条件が違います。2 また、MILDとWBTBを組み合わせた結果は、その組み合わせの成績です。個々の方法を選ぶときは、数字と一緒に条件を確かめましょう。

睡眠を大切にしながら試す

方法を試すときも、必要な睡眠を取れることを優先してください。途中で起きる方法なら、その後に眠る時間も確保しましょう。眠れなくなったり、翌日の生活に支障が出たりしたら休みます。

金縛りについて、NHSは十分な睡眠と規則的な寝起きを勧めています。繰り返す金縛りで眠るのが怖くなったり、睡眠不足による疲れが続いたりする場合は、医療機関への相談が目安です。3

技法を試した週の睡眠の質を調べた研究もあります。WBTBの研究欄で、結果と参加者の条件を紹介しています。方法ごとの注意は、各ページの手順の近くに残しています。
