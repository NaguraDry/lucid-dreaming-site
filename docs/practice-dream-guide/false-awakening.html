偽りの目覚め（偽覚醒）

目が覚めて、いつものように行動していた。ところが、あとで本当に目が覚め、その起床場面も夢だったと分かった。離脱界隈では、こうした体験を偽りの目覚めと呼びます。研究では偽覚醒と呼ばれ、英語では false awakening といいます。12

ここでは、明晰夢や離脱の前後にも現れるこの体験と、気づいたときの過ごし方を紹介します。

どんな体験なのか

自分の寝室で起き上がる、朝食を取る、出かける支度をするなど、普段の生活に似た場面が夢になることがあります。寝床にいるつもりで「まだ眠れない」と考えていた場面が、実は夢だったという報告もあります。2

明晰夢や金縛りとの関わり

明晰夢は、夢を見ている最中に「これは夢だ」と分かっている夢です。偽りの目覚めの場面でも、何かおかしいと気づき、夢だと分かれば、そこから明晰夢として過ごすことができます。明晰夢の経験者を対象とした調査でも、偽りの目覚めとのつながりが報告されています。3

金縛りでは、意識があるのに体を動かせないと感じます。一方、偽りの目覚めでは、起き上がったり歩いたりしているつもりになることがあります。金縛りの後に偽りの目覚めが続いた記録もありますが、体験としてはこの違いがあります。2

気づいたときは

「起きたはずなのに、何か違う」と思ったら、いったん立ち止まり、周囲の様子を見てみましょう。リアリティチェックも、夢かどうかを考えるための一つの工夫です。確認方法を繰り返すことより、今どんな場面にいると感じているかに目を向けてみてください。

夢だと気づいて興味が湧いたら、その場の景色を眺めたり、やってみたかったことを思い出したりしてもよいでしょう。驚いたり怖くなったりしたときは、何かを達成しようとせず、落ち着くことを優先してください。

確かめるために高い所から飛ぶなど、体を危険にさらす行動はしないでください。日中も何度も確認し続ける必要はありません。

目覚めた後に残しておくこと

覚えているうちに、次のような点を短く書いておくと、体験を振り返りやすくなります。

  • どこで目覚めたつもりになり、何をしていたか。
  • 夢の最中に気づいたのか、起きてから分かったのか。
  • 前後に覚えている夢や、体を動かせない感覚があったか。

細部を思い出せないところは空欄のままで構いません。書き方は夢日記でも紹介しています。記録を終えたら、普段の生活や休息に戻りましょう。

研究で分かっていること

Buzzi（2011）は、明晰夢の経験者から偽覚醒についての自己報告を集めています。こうした人たちがどう体験しているかを知る資料であり、一般の人にどのくらい起こるかを示す調査ではありません。3

Mainieriら（2021）は、5人から金縛り5件と偽覚醒2件を記録しました。この2件の偽覚醒では、脳波にレム睡眠に近い特徴が見られました。ただし、睡眠の問題で受診した少数の人の記録で、偽覚醒の開始時点を正確に特定できなかった例もあります。偽覚醒すべての仕組みや、明晰夢へ移る方法の効果まで確かめた研究ではありません。2

あわせて読む

  • リアリティチェック — 夢かどうかを確かめる工夫と、その研究。
  • 金縛り — 体が動かないと感じる体験と、怖さがあるときの対応。
  • DEILD — 実際に目覚めた直後、明晰夢へ戻ることを目指す方法。
