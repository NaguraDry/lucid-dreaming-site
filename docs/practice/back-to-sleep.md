# 二度寝を狙う

一度目を覚ましてから、もうひと眠り。その寝直しに、夢の中で気づくための練習を組み込みます。

まとめでは「[トイレマン法](https://w.atwiki.jp/wiki13_ridatu/pages/17.html)」が有名です。寝る前に多めの水を飲んで、尿意による中途覚醒を利用するものですが、これも二度寝法の応用と考えられます。[^vip]

ここでは[二度寝法（WBTB）](../techniques/wbtb.html)と[SSILD（感覚循環法）](../techniques/ssild.html)の組み合わせを紹介します。SSILDは、見え方・音・体の感覚へ、順に軽く注意を向ける方法です。[^aspy]

## 寝直す前に、感覚をひと巡り

以下は[Aspy（2020）](https://doi.org/10.3389/fpsyg.2020.01746)の家庭研究で用いられた手順に沿った案内です。始める前に流れを読んでおき、起きた後にも十分眠れる日を選びましょう。

1. **一度眠ってから起きる。** 研究では、就寝約5時間後にアラームを設定しました。基本の手順は、寝床から出て止める位置に置くものでした。この5時間は、睡眠を終える時刻ではありません。
2. **いったん目を覚ます。** 起きている時間は、この研究では一律に決められていません。練習を始めてもすぐ寝落ちしてしまう場合には、数分間明かりをつけ、手順を読み返して目を覚ますよう案内されていました。寝直しにくい場合の調整は、下の「眠りに戻りにくいときは」で紹介します。
3. **楽な姿勢で横になり、目を閉じる。** ここまでが二度寝法（WBTB）の準備です。ここからはSSILD（感覚循環法）を使います。まず、まぶたの裏の暗さや見え方へ、力まず注意を向けます。何も見えなくても構いません。
4. **音、体の感覚へ移る。** 聞こえる音に注意を向け、次に布団に触れる感じや体の重さなどへ移ります。感覚を探し出したり、強めたりしようとせず、気づく程度にします。
5. **短い巡回から、ゆっくりした巡回へ。** 「見え方→音→体」を各2〜3秒ほどで4巡。その後、各20秒ほどのゆっくりした巡回を4〜6回行います。秒数を正確に数える必要はありません。
6. **終えたら、普段どおり眠る。** ゆっくりした巡回を終えたら練習を切り上げ、眠りに戻ります。[^aspy]

時刻・回数は、この研究で使われた条件です。全員に最適な設定として決まったものではありません。

## 眠りに戻りにくいときは

研究では、眠りに戻りにくい人には、明かりを消したままにする、アラームを枕元へ置く、音を控えめにするという調整も案内していました。[^aspy] 眠れないのに練習を繰り返すより、その日は休むことを優先してください。

次に目が覚めたときに機会があれば、[寝覚めを狙う](waking.html)という入り方も選べます。

## まとめの二度寝法との関係

「最近幽体離脱にはまった まとめ」にも、一度起きて寝直す二度寝法が載っています。[^vip] 起きた後を使う点は共通しますが、このページで示した具体的な巡回は、海外研究のSSILDの手順です。まとめの方法やトイレマンの実践が、SSILDと同じものだったという意味ではありません。

## 研究で分かっていること

Aspy（2020）は355人が完了した家庭研究です。SSILDとWBTBを組み合わせた群では、普段どおりに記録した週より、技法を行った週に明晰夢を報告した夜の割合が増えました。MILDとの比較では有意な差はありませんでした。[^aspy]

これは明晰夢の自己報告を調べた結果で、体から抜ける感覚の成功率ではありません。二度寝だけの効果とも分けて読みます。研究手順や睡眠への負担の詳しい説明は[WBTBの技法解説](../techniques/wbtb.html)、別の版との違いは[SSILDの技法解説](../techniques/ssild.html#研究版との違い)にあります。
