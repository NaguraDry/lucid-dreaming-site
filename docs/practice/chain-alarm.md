# アラームで寝覚めを作る

自然に目が覚めたときをつかみにくいなら、目覚ましを使う方法もあります。**チェーンアラーム法**は、アラームを区切りに、眠りへ入る機会を繰り返すコミュニティの実践法です。

## まとめに載っている進め方

「最近幽体離脱にはまった まとめ」の「チェーンアラーム法・改」は、次の流れを紹介しています。[^vip]

1. **30分後に目覚ましを設定し、離脱を試す。** 横になり、眠りへ入る機会を使います。
2. **目覚ましが鳴ったら、その回を区切る。** 続ける場合は再び30分後へ設定し、もう一度試します。

30分は、まとめに記載された設定例です。研究で確かめられた最適な間隔ではありません。同じ資料は、体験している途中でもアラームで起こされる点を欠点として挙げています。[^vip]

試す場合は、開始前に終える時刻を決め、夜の睡眠時間を削らない範囲にしましょう。眠れなくなったり、疲れや眠気が残ったりする場合は繰り返さず、アラームを解除して休んでください。

## 目が覚めた後、どうするか

アラームは、目覚める機会を作る仕掛けです。その後に何を試すかも、先に決めておくと流れを追いやすくなります。

目覚めたことに気づき、まだ眠気が残っているときは、[寝覚めを狙う](waking.html)の手順を試す選択肢があります。一度起きてから寝直すなら、[二度寝とSSILD](back-to-sleep.html)へ進めます。

この二つへの案内は本サイトの選択肢の整理です。まとめのチェーンアラーム法自体が、SSILDやDEILDとの組み合わせを検証したものではありません。

## 近い着眼点の海外研究

SmithとBlagrove（2015）は、84人の質問紙調査で、アラームのスヌーズを使う回数と明晰夢の頻度に関連があると報告しました。[^snooze]

スヌーズを使う人に明晰夢の報告が多かったという関連であり、繰り返しアラームを鳴らすことで明晰夢が増えると確かめた実験ではありません。チェーンアラーム法そのものや、30分間隔を裏付ける研究としては扱いません。

目覚めと寝直しに注目する点で、比較して読める資料として紹介します。
