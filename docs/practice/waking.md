# 寝覚めを狙う

目が覚めた時、その瞬間を自覚できるのであれば、起き上がる前に、その寝覚めを離脱のきっかけとして使ってみます。

夢を見ていた覚えがなくても構いません。直前の夢を思い出したり、夢の続きを再現したりすることを、始める条件にはしません。

参考になるのは **[DEILD（覚醒時不動法）](../techniques/deild.html)**。夢から目覚めた直後に、目を閉じたまま静かにして再入眠し、自覚を保ったまま夢へ戻ることを狙う実践です。[^klace][^wiki] このページでは、夢の記憶の有無にかかわらず、目が覚めた瞬間の自覚を入口にします。目を閉じたまま静かにして、景色や体の感覚の変化を手掛かりに、離脱へ移ることを狙います。

## 目覚めたら、こうしてみる

1. **眠る前に、試すことを決める。** 「目が覚めた瞬間に気づいたら、そのまま静かにしてみよう」と意図しておきます。
2. **目覚めた自覚を保ち、目を閉じたまま静かにする。** 急いで起き上がらず、楽な姿勢でじっとしてみます。夢を思い出したり、場面を作ったりする必要はありません。体がかゆい、姿勢がつらいときまで我慢する必要はありません。
3. **景色や体の感覚が変わったら、その場で行動してみる。** 目を閉じているのに部屋が見える、体が浮くように感じるなどの変化に気づいたら、その場面で動いたり、周囲を見たりすることを試します。金縛りや、体が抜ける感覚が来るまで待つ必要はありません。

場面を思い浮かべる方がやりやすければ、落ち着ける場所や、触れたり動いたりする感覚を想像する選択肢もあります。直前の夢を覚えている場合に、その場面を使っても構いません。これらは後続のDEILDガイドにある補助的なやり方です。[^wiki]

## 起きたつもりでも、まだ夢の中だったら

寝床から起きて普段どおりに過ごしていたのに、あとで本当に目が覚めた。こうした体験を[偽りの目覚め](../false-awakening.html)といいます。起床場面で何かおかしいと気づいたら、[リアリティチェック](../techniques/reality-checks.html)などで夢かどうかを確かめるきっかけになります。

体が浮く、転がる、寝床から抜けるように感じる場合もあります。ただし、抜ける感覚が離脱の条件というわけではありません。夢の場面へそのまま移ることも含めて考えます。

## うまくいかなかったら

目が冴えた、特に変化を感じなかった、離脱せずそのまま眠った。その一回だけで、動いたせい、集中が足りないせい、と決めつけなくて大丈夫です。眠れなくなるほど続けず、その回は切り上げましょう。

目覚める機会を作って試したいなら、[チェーンアラーム法](chain-alarm.html)も読めます。

## 手順と根拠を詳しく読む
