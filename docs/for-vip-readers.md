# 「最近幽体離脱にはまった　まとめ」に親しんできた方へ

二度寝法、起きたら動かない法、指マン法。まとめで親しんできた方法を海外の明晰夢の資料と見比べると、よく似た進め方が見つかります。なじみのある実践から、別の説明や工夫、研究へと読み進められることが、このサイトを作った理由の一つです。

## 知っている方法から、その先へ

[「なじみの方法と、海外の対応する技法」](choosing-method.html#なじみの方法と海外の対応する技法)に、二度寝法とWBTB、起きたら動かない法とDEILD、指マン法とFILD、１氏の方法とWILD、金縛り経由の入口をまとめました。各ページから、海外で紹介されている手順や、その方法に関わる研究をたどれます。

たとえば、二度寝の機会を使うWBTBのページからは、寝直す前にMILDやSSILDを行った研究へ進めます。指マン法に似たFILDのページでは、考案者がどのような手順を紹介していたかを読めます。研究がある方法も、主に実践者の経験として伝わる方法も、それぞれの出典とともに紹介します。

まとめで楽しんできた体験や、試してきた方法を出発点に、気になるところから読んでみてください。

## なじみの言葉で読みつなぐ

本文では、初めて読む方にも伝わるよう、現実や夢といった一般的な言葉も使っています。まとめでは「渡辺」を普段の現実世界、「名倉」を離脱後に体験する世界の呼び名として説明しています。[^vip-terms]

| まとめの呼び方 | このサイトでの書き方 |
| --- | --- |
| 渡辺 | 現実、覚醒中。場面や状態に合わせて書き分けます。 |
| 名倉 | 夢の中、夢の世界、離脱体験の中。元の報告の文脈に合わせます。 |

「名倉」という呼び方だけから、夢だという自覚があったかまで決めることはしません。夢だと自覚している体験には「明晰夢」を使い、どのように感じたかという報告と、研究上の分類を分けて説明します。

「離脱」は体験の呼び方として引き続き使います。「リアリティチェック」もそのままです。原資料の題名や用語そのものを紹介するときは、元の表記を残します。

## 楽しみたい体験を入口に

夢の内容を自由に変えることだけでなく、その場にいるような鮮明さや、夢の中の相手との交流に関心がある方にも読んでもらえる資料を目指します。

「最近幽体離脱にはまった　まとめ」には「パートナー」や「ガイド」をめぐる説明・体験談があります。[^vip-partner] 海外の DreamViews にも、夢の中で助けになる人物を指す dream guide という用語があります。[^dream-guide] 呼び名や役割がすべて同じというわけではありませんが、夢の中の相手との関わりを楽しみ方の一つとして紹介していきます。相手との交流を必須の目標にするものではありません。

[離脱した後](after-entry.html)では、周囲の景色や感覚を味わうこと、探索や人物との交流など、入った先での楽しみ方を紹介しています。
