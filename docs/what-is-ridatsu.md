# 幽体離脱って、<br>どんな体験？

**幽体離脱と明晰夢の関係を知りたい方へ**<br>
呼び方や捉え方、このサイトの考え方は[「離脱の4つの立場」](four-perspectives.html)で紹介しています。

## その場にいる自分として、見たり、動いたりする

このサイトで紹介するのは、寝ている間に、別の場所にいるように感じ、そこで自分の意思で動き、過ごすような体験です。目の前の景色を眺めたり、何かに触れたり、ときには空を飛んだりすることもあります。[^activities]

心に描いていたことを、その場にいる自分の体験として味わう。幽体離脱や明晰夢には、そんな面白さがあります。

ときには、現実と見間違えるほど、景色や感触が非常にリアルに感じられることもあります。[^realism]

ただし、自分の意思で行動できることと、すべてを思いどおりに変えられることは別です。[^control]景色や感触のはっきりした感じにも幅があり、体験の途中で変わることがあります。[^vividness]

## 始まり方は、一つではありません

体から抜けるような感覚を経て始まることもあれば、気づいたら別の場所にいることもあります。[^beginnings]また、見ている夢の途中で「これは夢だ」と気づき、そこから自分の意思で行動することもあります。[^realism]

「幽体離脱」という名前から、体から抜ける瞬間を想像するかもしれませんが、そうした感覚がなくても体験は始まります。
