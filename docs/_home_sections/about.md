名倉ドライといいます。離脱歴は15年以上。冒険やパートナーとの交流を楽しみ、その体験をブログに綴ってきました。

一方で、こうした体験をもっと多くの人が楽しめるようにならないか。そんな思いで、さまざまな離脱法を探ってきました。

その中で、離脱コミュニティで少しずつ編み出されてきたと思っていた方法の多くが、海外で明晰夢の技法として紹介されているものと、とてもよく似ていることを知りました。そこには、詳しい手順や実践の工夫に加え、明晰夢の技法を調べた研究データもありました。

離脱に興味はあっても、とても難しそうだと感じていませんか。けれども、ここで紹介する明晰夢のテクニックを用いれば、思われているほど遠い体験ではなくなるかもしれません。こうした体験がもっと身近なものになることを願って、このサイトを作っています。

このサイトでは、明晰夢の研究と実践を手掛かりに、離脱を目指す方法を紹介します。手順とともに、分かっていることや研究の条件も伝えていきます。
