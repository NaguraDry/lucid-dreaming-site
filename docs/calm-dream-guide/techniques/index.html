技法一覧

夢の記録、睡眠のタイミング、明晰夢への入り方を扱うページをまとめました。詳しい手順と根拠は各ページを参照してください。

全員が順番になぞる訓練コースや、次へ進むための回数・達成基準は設けない。関心のある項目から、手順の出典と確かめられている範囲を読んでほしい。以下の並びは、効果の順位や必須の実践順序ではない。

夢の記録と睡眠のタイミング

  • 夢日記：思い出した夢を記録し、振り返る。
  • WBTB：睡眠の途中で一度起き、再び眠る。他の技法と組み合わせた研究がある。12

MILD と SSILD

  • MILD：夢の中で気づく意図やイメージを用いる。系統的レビューで、比較的強い裏付けがあると評価された技法。3
  • SSILD：視覚・聴覚・身体感覚へ順に注意を向ける。2020年の研究ではMILDとの成績に有意差はなかったが、厳密な同等性の証明ではない。2

同研究で試された混合手順は、比較した各手順を上回らなかった。あらゆる併用が無効、あるいは必ず一つだけ選ぶべきだと示す結果ではない。2

日中のリアリティチェック

  • リアリティチェック：今が夢かどうかを確かめる練習や、夢の中での確認として紹介される。2017年の研究では、単独の1週間の練習で有意な改善は確認されなかった。MILDへの追加寄与も、その研究だけでは確定できない。1

覚醒・入眠時からの移行

  • DEILD：夢から覚めた直後の再入眠を利用する実践。
  • WILD：覚醒から夢への移行で自覚を保つことを狙う方法や、その入り方を指す。
  • FILD：小さな指の動きを使う、コミュニティ投稿由来の手順。
  • 金縛りからの離脱：睡眠に伴う金縛りと、夢への移行に関する実践報告を分けて読む。4

これらは各ページで由来と検証の範囲を示す。短時間の移行を狙う説明があっても、その時間内の成功や負担のなさを保証するものではない。

感覚キューを使う研究

  • TLR：睡眠前の認知訓練と、睡眠中の感覚キューを組み合わせる研究。実験室版と家庭版では条件や評価方法が異なる。56
