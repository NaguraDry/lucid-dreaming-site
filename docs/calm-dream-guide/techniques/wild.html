WILD（覚醒から夢へ移る）

WILDは、眠りに入るときに自覚を保ち、そのまま明晰夢へ入ることを目指す方法です。Wake Initiated Lucid Dreamの略で、一つの決まった手順というより、明晰夢への入り方を指す言葉です。1

以下は、DreamViewsの複数のコミュニティガイドをもとに、このサイトで整理した実践例です。23 一つの研究で検証された手順ではなく、この組み合わせ全体の成功率は分かっていません。

具体的な進め方

1. 眠りに戻るとき、楽な姿勢を取る

WBTBで一度起きた後や、昼寝の機会を使う説明があります。横になり、楽に眠れる姿勢を取ります。2

唾を飲み込みたくなったら飲み込み、姿勢がつらければ直しましょう。静止を強調するガイドもありますが、DreamViewsの解説では、こうした動きをしてもよいと説明されています。2

2. 呼吸やイメージに注意を向ける

呼吸、数を数えること、体の感覚、入眠時に浮かぶイメージなどから、注意を向けやすいものを選びます。全部を一度に行うのではなく、自分が続けやすいものを使います。3

3. 眠りに入る変化を見守る

眠りに入るときには、像や音、浮くような感覚を経験することがあります。4 特定の感覚が現れるのを待ち続けるより、選んだ呼吸やイメージにゆるく注意を向けます。5

金縛りは必須の段階ではありません。音や振動など、一つの感覚だけで「もうすぐ成功する」と判断するより、夢の場面と自覚に目を向けましょう。

4. 夢の中にいると気づく

イメージが、そこにいるように感じる場面へ変わる過程がガイドで説明されています。目指すのは鮮明な像を見ることだけでなく、その場面で「これは夢だ」と分かっている状態です。3

確かめ方としてリアリティチェックも紹介されています。具体的な方法と、それぞれの限界はリンク先で読めます。

続けるときのコツ

Sageousのガイドは、力まずに注意を保つことを勧めています。眠ろうとしながら細かな変化を追い続けるのではなく、楽な姿勢と軽い注意を意識する、という実践上の助言です。5

眠れない・怖いとき

眠れなくなったり、怖さや苦痛が出たりしたら、試すのをやめて休みましょう。つらい静止や、嚥下の我慢は必要ありません。
金縛りが怖い場合は中断と相談の目安へ。共通の睡眠への配慮はこのサイトの根拠の読み方にまとめています。

研究で分かっていること

LaBergeの研究解説には、一時的な覚醒を挟んで明晰REM睡眠へ入った記録があります。これはWILDという入り方を確認した記録で、上の手順を試した回数に対する成功率ではありません。1

Radugaの覚醒時誘発法にも自己報告の研究があります。ただし、複数の技法を含む商業セミナーの記録で、対照群はありません。このページの進め方全体の効果や、他の方法との優劣は、これらの研究からは分かりません。6

「体が眠り、意識だけが残る」という説明は、体験を表す比喩です。体と意識が実際に分離するという意味ではありません。研究と実践記事の違いは共通の案内で説明しています。
